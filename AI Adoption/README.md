# AI Adoption

HumanEvoX | Client enablement, enterprise AI adoption, learning delivery and programme governance.

This is a separate **main portfolio folder**, as requested. The original three project folders and their case-specific evidence are preserved. A fourth collection includes eight function-specific Agentic AI adoption roadmaps.

## Projects

1. **[Project 34 — Microsoft 365 Copilot Adoption & Enablement Consultant](34_Business_Oriented_Microsoft_365_Copilot_Adoption_and_Enablement_Consultant/)** — stakeholder discovery, workshop facilitation, user exercises, champions, readiness, security and a synthetic adoption KPI/reporting example.
2. **[Project 47 — AI Adoption Program Management](47_AI_Adoption_Program_Management/)** — fictional UAE university case covering adoption governance, programme charter, 30/60/90-day roadmap, AI literacy, risk and incident management, stakeholder RACI and benefits reporting.
3. **[AI Platform Training & Onboarding — Contact Center](AI%20Platform%20Training%20%26%20Onboarding%20-%20Contact%20Center/)** — original simulated AI-creative-platform onboarding package: facilitator workshop, practical prompt lab, user troubleshooting guide, learner competency and synthetic feedback/performance calculation.

4. **[Practical Roadmap for Agentic AI Adoption in HR](Practical%20Roadmap%20for%20Agentic%20AI%20Adoption%20in%20HR/README.md)** — eight separate HR workstream projects, each with a business case, organizational readiness, UAE-first governance, risk controls, supervised pilot and scaling criteria. These are adoption designs, not claimed enterprise deployments.

**Integrity:** No live client training, employer assignment, real-world adoption outcome, Microsoft tenant rollout or third-party model test is claimed. Read each project's README for specific limitations.
