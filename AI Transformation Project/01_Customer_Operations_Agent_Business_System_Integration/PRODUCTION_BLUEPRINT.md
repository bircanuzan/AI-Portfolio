# Production engineering and change management roadmap

**Discovery:** Process mapping, baseline volume, exception rates, opportunity scoring, real system integration ownership, data privacy and UAE regulatory checks.

**Architecture options for authorized deployment:** Microsoft Graph, Salesforce/HubSpot or insurance CRM, approved data/knowledge APIs, Azure AI Foundry/OpenAI API or Copilot Studio, managed SQL/Dataverse, Power Automate, secure secret management, Power BI. None are connected in the offline demo.

**Security:** SSO/OAuth token scopes, end-user delegated access and least privilege, encryption, logging/retention, DLP, prompt injection defenses, PII minimization, content governance, human approval gates and rollback.

**AI evaluation:** golden test sets, factual error rate, source traceability, retrieval access checks, reviewer time, hallucination rate, scenario coverage, business owner signoff.

**Business value:** Net productivity requires actual measured workload including human review and rework. Only finance-validated cost reductions and verified time measurements may be reported as results. Model usage and synthetic calculations do not prove ROI.

**Go-live sequence:** business intake -> sandbox proof -> security assessment -> limited human-reviewed pilot -> UAT and negative tests -> adoption and change management -> measured quality/outcomes -> decision to scale or stop.

**Not an insurance decision-maker:** Never infer insurance eligibility, premiums or coverage automatically. Escalate to authorized staff.
