## Demonstration
[Open the standalone interactive talent operating dashboard](Executive_Talent_PowerBI_Dashboard_Demo.html).

Power BI is modelled as an *optional, separate* cross-system analytic layer for people, Finance, learning and project readiness data. This is a Power BI build **specification and HTML prototype, not an exported PBIX or live tenant dashboard**. The Power BI and Oracle cases share a fictional KPI baseline for comparability but demonstrate different architecture and executive competencies.
