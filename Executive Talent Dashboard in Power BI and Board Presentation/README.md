# Executive Talent Dashboard in Power BI and Board Presentation

> **INDEPENDENT INTERVIEW PORTFOLIO CASE • SYNTHETIC DATA • NOT A COMPANY'S INTERNAL RESULTS**

Two independent talent-intelligence demonstrations designed to communicate an executive Head of Talent Development operating plan and decisions in a fictional international clean-energy organisation.

## 1. [Executive Talent Dashboard in Power BI & Board Presentation](01_Executive_Talent_Dashboard_Power_BI/README.md)
Power BI-ready talent operating KPI definitions, CSV scorecard, financial/people risk interpretation, model logic and a three-slide executive storyboard. Power BI is an **optional cross-system consolidation capability**, not asserted to be any real company's reporting platform.

## 2. [Executive Talent Dashboard & Executive Reporting Using Oracle Fusion HCM](02_Executive_Talent_Dashboard_Oracle_Fusion_HCM/README.md)
**Primary interview demo.** Oracle Fusion Cloud HCM Talent Management and Performance/Goal Management are the proposed source. Oracle OTBI provides transactional KPI dashboards, goal alignment, performance and talent-review reporting, and succession analyses. **Oracle Analytics Publisher (formerly BI Publisher)** enables formatted monthly, quarterly and annual packs. **Oracle Fusion HCM Analytics** is optional, separately licensed, and useful for historical workforce intelligence. An organisation's PMR framework consolidates performance and finance reporting; its underlying software is **not identified**.

The portfolio contains an **interactive, offline dashboard demonstration** and a three-slide board narrative for each project, plus an Oracle Analytics Publisher report mock-layout.

**Important evidence boundary:** Every numeric people KPI, financial amount, risk and board proposal is invented for teaching / interview discussion. The original finished editable PPTX/PDF artifacts were created outside GitHub as companion presentation deliverables. Neither a production Oracle tenant nor Power BI Service/PBIX was accessed or configured. Do not claim the demo is a screenshot or approved executive report.

### Executive operating cycle
Corporate strategy → critical roles and skills → employee goal cascade → performance management and talent review → development and successors → risk/cost performance → leadership decisions → 90-day evidence.
