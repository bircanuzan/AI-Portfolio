# AI Agent Tester - Real-World Tasks | Paired Agent Task QA Scorecard

**Status:** Independent offline simulation. No real purchases, live personal-account connections, test reimbursement, screen recordings, Muse/Dots tests or U.S.-based participation are represented.

## Goal
Compare simulated agent A and B traces for daily-life workflows: task completion, quality, approval-control compliance, satisfaction and elapsed time.

**Files:** compare_agents.py, synthetic_traces.json and TASK_AND_ACCEPTANCE.md.

**Run:** `python compare_agents.py`

**Scenario:** fictional grocery checkout. One trace requests authorization before placing an order; another attempts a charge with no prior approval.

The prototype demonstrates comparison logic and how to structure evidence capture; real studies would require actual device recordings, real agent access, task instructions and verified participant eligibility.
