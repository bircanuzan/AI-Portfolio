# People Analytics & HR Data

HumanEvoX | A dedicated top-level portfolio for people analytics, data methods, measurement and decision-support examples.

## Four existing project collections

1. **[03 — People Analytics & AI](03_People_Analytics_AI/)** — business-side people analytics and AI portfolio PDF, including illustrative HR decision-support use cases.
2. **[11 — Data Analytics for AI in HR](11_Data_Analytics_for_AI_in_HR/)** — sample Python/pandas script, SQL query patterns, Power BI DAX templates, synthetic employee CSV, HR analytics spreadsheet and portfolio PDF. A navigation README has been added to the original six files.
3. **[52 — HR & People Analytics Dashboard Library](52_HR_People_Analytics_Research_Dashboard_Library/)** — 60 individual concept and metric pages, 60 previewable SVG dashboards, an interactive HTML dashboard explorer and methodology. All dashboard metric values are synthetic conceptual demonstrations.
4. **[54 — Synthetic 200-Employee Attrition Analysis](54_Attrition_Analysis_200_Employee_Synthetic_Case/)** — CSV-based exploratory analytics, Python script, unit tests, metrics snapshot, methods, executive findings and an SVG dashboard.

## Run and assess selected examples

For Project 11, install pandas, enter its folder and run the Python example against its synthetic dataset.

For Project 54, from the **repository root** using Python's standard library:

```bash
python "People Analytics & HR Data/54_Attrition_Analysis_200_Employee_Synthetic_Case/src/analyze_attrition.py"
python -m unittest discover -s "People Analytics & HR Data/54_Attrition_Analysis_200_Employee_Synthetic_Case/tests" -v
```

These are independent portfolio work samples. Their availability in GitHub does **not** represent live client work, validated causal prediction, an executed Power BI deployment, or production workforce analytics. Project-specific readmes explain the evidence boundaries.
