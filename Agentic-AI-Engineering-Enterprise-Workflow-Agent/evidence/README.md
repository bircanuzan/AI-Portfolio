# Evidence log

No client delivery, external API response, live model output or successful n8n run is claimed by this starter. RESULT.csv contains only empty fields until an actual recorded execution.

For each trial capture: UTC time, commit SHA, runtime, dependency versions, input (synthetic/redacted), sources retrieved, tool/API request identifiers, real model output, ground truth, rubric, reviewer decision, latency, cost and incident classification.

Retain failures and fixes, not just successful examples. Remove API tokens, candidate PII, real payroll and HR data from any public artifact. Use sanitized screenshots and a screen-recorded demonstration with visible local execution. Do not create mock screenshots presented as real.
