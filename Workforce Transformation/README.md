# Workforce Transformation | HumanEvoX portfolio

**Purpose:** Translate business strategy and AI-enabled change into defensible decisions about work, workforce capacity, roles, skills, recruitment and employee transitions.

**Evidence classification:** Independent, fictional UAE service-company simulation with synthetic workloads and capability data. Not a Click Start project, employer assignment, paid engagement, client deployment, production workforce-planning engine, or actual workforce outcome. Employment decisions are reserved for human leadership and qualified HR/legal professionals.

## Connected project sequence

1. [01 — Capacity and Headcount Decision Lab](01_Capacity_and_Headcount_Decision_Lab/README.md): build a task-and-capacity baseline; test redesign vs hiring scenarios; measure review burden and uncertainty; run a reproducible Python model.
2. [02 — Role Architecture, Skills and Redeployment](02_Role_Architecture_Skills_and_Redeployment/README.md): redefine human/AI tasks, decision rights, skills, role profiles, learning and structured assessment.
3. [03 — Workforce Transition and Performance Model](03_Workforce_Transition_and_Performance_Model/README.md): manager consultation, people-risk controls, role transition, change plan, adoption and quality KPIs.

**Case:** Fictional 'Atlas UAE Shared Services', with employee service, customer operations and recruitment coordination teams preparing for AI-assisted workflows. The operating question is: *When a team requests more headcount, should leaders hire, redesign work, improve capability, or combine these options?*

**Methods and skills:** Strategic workforce planning; organization design; workload sampling; service-level measurement; FTE demand modelling; process/task decomposition; capacity sensitivity; skills taxonomy; role architecture; competency-based assessment; structured interviews; RACI; human/AI decision rights; redeployment; ADKAR-informed adoption; privacy-sensitive HR change; stage-gated implementation; KPI definition.

**Tools demonstrated:** Python 3 stdlib, CSV data, reproducible unit tests, Markdown decision records. **Proposed production options (not operated here):** Excel/Power Query, Power BI, Visier, Workday, Oracle Fusion HCM, SAP SuccessFactors, Microsoft 365 Copilot/Copilot Studio, Teams, Microsoft Forms and Power Automate. Integration to employer HRIS requires security approval and data minimization.
