# Evidence register: what is demonstrated, and what is not

| Artifact | Provenance / execution | Can claim | Must NOT claim |
|---|---|---|---|
| Six role families | Independently written interpretation of screenshot topics | Role map and entry-route comparison | Verified current UAE vacancy availability |
| Role matcher | Source code + self-reported example levels | Explainable weighted scoring framework | Validated job-market prediction / ATS compatibility |
| Attrition | 200 generated synthetic records + computed baseline | Reproducible descriptive demo / CSV audit | 200 real employees, achieved retention improvement, predictive accuracy |
| Screening risks | Original 12-case hypothetical register | Risk identification and release gate design | Tested named ATS, proven bias or legal compliance certification |
| HR assistant | Offline deterministic router, 20 hand-authored prompts | Reproducible keyword routing framework and sample test comparison | Claude-powered agent, Copilot Studio production deployment, real company policy compliance |
| Claude-compatible skills | Four human-readable SKILL.md prompt packs | Prepared skill instructions ready for review/import | Installed, authenticated, executed or benchmarked Claude tools |
| Interview/CV templates | Original editorial prompts and structure | Reusable drafting/checklist examples | Successful applications or prior work not evidenced in CV |

### Counts from the original synthetic exercises
- Attrition records: **200**.
- Screening-risk register: **12** synthetic cases.
- Policy QA: **20** prompts, with each expected route in CSV.
- Failure evidence remains in the evaluation summary; no pass rate is a model accuracy claim.

### Evidence advancement checklist
For stronger claims, store a redacted source/config version, execution command, date, exact prompts, actual outputs, assessor labels, identifiable test failures and retest outcome. For hosted tools, include tenant/provider details (redacted), consent/legal basis and environment, while never exposing secrets or personal data.

**No client deliverable, employer deployment or professional certification is inferred solely from GitHub source files.**
