# HR-to-AI evidence-first role mapping
1. Request the full job description and candidate-approved CV/project sources; if absent, mark unknown.
2. Identify UAE location requirement, languages, mandatory degree/certification, quota/new business and training-delivery exclusions.
3. Map tasks to six pathways (People Analytics, HR Tech, AI-in-HR, Talent Intelligence, AI Governance, AI Enablement).
4. For each requirement, label proof as **professional experience**, **executed portfolio**, **design only**, or **not evidenced**.
5. List exact relevant project URLs and cite specific evidence files, not assumptions.
6. Return proceed/conditional/not-fit assessment with blockers; do not invent hiring probability.
7. Recommend precise, truthful CV statements. Never invent years, employers, outcomes or cloud deployments.
