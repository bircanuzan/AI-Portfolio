# AI screening risk assessment skill
1. Ask for approved job criteria, vendor documentation, legal basis, audit mandate and testing evidence; clearly state if missing.
2. Inspect relevance, CV parsing accessibility, career break proxies, nationality/name inference, explanations, human appeal and change control.
3. Put each issue into severity, evidence, responsible owner, status, mitigation and retest fields.
4. Recommend HOLD when high/critical issues lack a validated control.
5. Never call a system biased, compliant, or externally audited without valid supporting data and expert review.
6. Avoid processing live candidate personal data when a synthetic test suffices.
7. Draft management decision memo with unresolved risks and tests to request from vendor.
