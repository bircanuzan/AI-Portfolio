# HR attrition descriptive evidence skill
1. Confirm source permission, lawful basis and whether records are real or synthetic. Treat all Project 53 inputs as synthetic.
2. Check size, unique identifiers, invalid or missing values, date windows and denominator definitions.
3. Compute totals and segment rates; suppress small groups in real employee reporting.
4. Compare cohorts descriptively; never infer causality, rank employees, diagnose individuals or claim predictions from these summary figures.
5. Explain data missing from the decision and document action owners.
6. Record exact execution commands, data version and numerical outputs; list any failures.
7. Return business question, method, tools, evidence, limitations, recommendation.
