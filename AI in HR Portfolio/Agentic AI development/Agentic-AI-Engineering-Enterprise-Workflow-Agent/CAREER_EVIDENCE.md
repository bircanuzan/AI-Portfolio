# CV and interview representation — truthfulness checklist

**Until deployment/test is verified:**
- "Created a Python/FastAPI starter for a bounded agentic workflow featuring document retrieval, a configurable HTTPS case-API adapter, a human-approval queue, pytest test cases and n8n import configuration. Personal GitHub engineering lab; live LLM integration and n8n deployment pending execution evidence."
- Do not say "deployed", "production-grade", "served clients", "n8n operational", "AI agent accuracy 98%" or "one year of AI engineer experience" without genuine records.

**After local executions:** cite exact test outputs, test counts, environment, failures and dated screenshots from actual runs.

**After a signed paid engagement through HumanEvoX:** CV may use "Self-employed AI Workflow Implementation Consultant — HumanEvoX" with true dates, client-permitted description, SOW-backed deliverables, metrics and reference (with permission). Always distinguish client delivery from independent portfolio learning.

**Technical interview demonstration:** explain difference between retrieval and LLM inference; why dynamic URL prompts are disallowed; how API timeouts trigger escalation; why a separate approver identity is required; how idempotent approval works; how to reproduce a failing test; how an n8n webhook connects to FastAPI; and what must change before deployment.

**Potential adjacent roles:** Junior AI Implementation / Integration, AI Application Testing, AI Operations, Enterprise SaaS Implementation, HRTech Delivery.
