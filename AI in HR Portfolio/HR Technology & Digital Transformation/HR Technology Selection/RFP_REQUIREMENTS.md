# HR service technology RFP — functional and nonfunctional requirements

**Procurement scope:** Employee-facing HR case-management / knowledge / workflow platform. Excludes replacement of payroll, Core HR and enterprise HCM.

| ID | Priority | Requirement | Acceptance evidence |
|---|---|---|---|
| FR01 | Must | Role-restricted HR enquiry intake and case routing | Case opened, routed, escalated and closed |
| FR02 | Must | Employee status tracking without disclosing private notes | Employee vs HR staff permission test |
| FR03 | Must | Named approval for sensitive requests | Approval captured, authorised, auditable |
| FR04 | Must | Configurable service catalogue, categories and SLAs | HR can update catalogue in nonproduction |
| FR05 | Should | Multilingual employee-facing content | Reviewed test of sample English/Arabic flows |
| FR06 | Should | Responsive accessible mobile interface | Keyboard / screen-reader usability audit |
| FR07 | Must | Exportable case and SLA data | Reconciliation with approved analytic model |
| NFR01 | Must | Enterprise SSO, RBAC and access logging | Security evidence and red-team review |
| NFR02 | Must | Defined data residency, retention, deletion and subprocessor terms | Current privacy and legal due diligence |
| NFR03 | Must | Encryption, backups and tested incident recovery | Security audit evidence |
| NFR04 | Must | Secure HRIS integration option; no default payroll write access | API spec, technical proof and IAM review |
| NFR05 | Should | Configurable deployment, support and training model | SLA, implementation proposal and references |

## Vendor response pack
Require: capability-by-requirement response, evidence link, product limitations, standard vs custom features, implementation calendar, third-party dependencies, data processing agreement, security certifications (verified by team), sample SLAs and three-year TCO assumptions.

## Evaluation rules
No product score before receiving proof. Disqualify solutions failing any mandatory privacy/security gate. Score compliant candidates against 0-5 scale and version the criteria before demos. Review weighted scores for evaluator conflicts and sensitivity to weight changes.
