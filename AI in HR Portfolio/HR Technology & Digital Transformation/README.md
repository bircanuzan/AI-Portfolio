# HR Technology & Digital Transformation

**Six distinct projects:** the original legacy PDF collection plus five complementary, independent case studies. This category covers HR technology **strategy, sourcing, employee experience, implementation management and employee-facing self-service design**. It does not duplicate Core HRIS/HCM data mapping, payroll processing, vendor-specific configuration or LLM agent engineering.

## Strict non-overlap boundaries
- **Transformation:** strategy and investment sequencing; not procurement or engineering.
- **Selection:** evaluation before contract award; no vendor endorsement or implementation claim.
- **Digital EX:** employee research and service blueprint; not a built portal.
- **Implementation:** project delivery and go-live of HR *case-management* platform; not HCM core configuration.
- **Self-Service:** employee-facing in-memory browser demo and safe routing; not an operational HR system or AI agent.
