# 02 — Role Architecture, Skills and Redeployment

**Business problem:** AI-assisted work changes task mix, but job titles, skills, assessment criteria and accountability lag behind.

## Deliverables

[Role architecture matrix](role_architecture.csv) specifies role purpose, retained human work, assisted work, automation candidate, accountability, essential skills and measurable success. [Skills and redeployment design](skills_and_redeployment.md) specifies a non-automated skill assessment and tailored learning/redeployment process.

## Operating model
- Start from **tasks** and outcomes, not job-title deletion. Map work using SIPOC/process walks, RACI, exception routes and decision rights.
- Classify tasks as human-led, AI-assisted with approval, or automatable only after testing and policy review. HR/legal/recruitment employment decisions stay with qualified humans.
- Define future role profiles, job families, competencies and 1–5 proficiency levels; align assessment criteria to actual tasks.
- Use structured interviews with anchored evidence, work samples, assessor calibration and accommodation/appeal processes.
- Build capability pathways: coaching, AI literacy, data interpretation, stakeholder judgment, responsible AI, workflow quality review and technology fluency.
- For incumbent people, use a confidential, human-reviewed development discussion; do not use algorithmic scoring to terminate or select employees.

## Technologies and skills
Role architecture, skills ontology, skill adjacency, capability assessment, job profiles, structured interviews, learning path design, human-in-the-loop roles, Oracle HCM/Workday/SAP SuccessFactors conceptual mapping, Microsoft Excel/Power BI and AI assistant support with human review.

**Evidence:** Design artefacts for fictional teams only. No people data or employment selection model.
