# HR-to-AI interview, CV, LinkedIn and case-study templates

## Interview preparation by seniority (do not invent experience)
**Coordinator / Analyst:** “Tell us about a process you improved.” Answer using **real** situation, your involvement, decisions, stakeholder feedback and verified measures. An offline GitHub demonstration is introduced as a *separate personal project*.

**Manager / Client Delivery:** “How would you lead AI-enabled HR process change?” Discuss sponsor, problem baseline, RACI, data quality, vendor limits, UAT, review checkpoints, KPIs and adoption; explicitly state which steps are designs rather than past projects.

**Governance / Responsible AI:** “What if an AI hiring assistant rejects non-standard CVs?” Cover evidence collection, HOLD decision, job-relevance criteria, human review, appeal, documented tests and vendor accountability. Avoid asserting a vendor is biased without measurement.

**Technical follow-up:** “What agent did you test, and what did it respond?” Specify *offline Python deterministic router*, 20 authored evaluation prompts, pass/fail output and actual failure cases. For live Copilot/Claude, answer **not deployed/tested unless separately evidenced**.

## Truthful CV project bullet templates
- “Designed an evidence-aware HR-to-AI role mapping framework across six job families; documented capability criteria, portfolio proof levels, and vacancy exclusion gates.”
- “Created a synthetic 200-record HR analytics example, with a reproducible Python descriptive analysis and defined limitations on causal interpretation.”
- “Authored a 12-scenario AI recruitment screening control register and an offline HOLD gate for unresolved high-severity issues; **not a production ATS audit**.”
- “Built an offline deterministic HR policy-question routing evaluator with 20 synthetic prompts and preserved mismatches for review; **not a live LLM deployment**.”

## LinkedIn project description template
**Problem:** HR transformation initiatives often lack transparent evidence of capability and practical governance.

**Project:** HumanEvoX HR-to-AI Role Map & Evidence Lab — six-role competency matrix, offline role scoring, 200-row synthetic retention case, 12 screening-risk scenarios, 20 policy routing tests, and original reusable prompt skills.

**Tools:** Python, CSV, JSON, GitHub, responsible-AI controls.

**Evidence note:** independent portfolio demonstration; synthetic data; no real client, live ATS or Claude/Copilot production deployment.

## One-page employer case-study structure
1. **Employer pain point:** state business decision and affected stakeholder.
2. **Your project role:** precise action performed versus proposed action.
3. **Methodology & tools actually used:** source, baseline, evaluation, human checkpoint.
4. **Evidence:** dataset size, command, test cases, results, failures and limitations.
5. **Decision and next step:** what a responsible employer should approve or test.
6. **Fit to this JD:** cite required competencies, and name any gap without disguising it.
