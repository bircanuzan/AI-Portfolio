An HSE module is globally mandatory but local language and site rules differ. The proposed executive intervention is: **Centralize standards and localize delivery with named approvals**.

## Methods and proposed tools
Hub-and-spoke model; RACI; translation QA; LMS rules. Technology references are proposed integration/assessment options only; current clean_energy_group systems and software licenses are unverified.

## Outcomes to demonstrate
**Primary KPI:** Regional compliance and validated localization rate. An authentic claim requires a signed baseline, real measured outcome, confounder assessment and owner approval.

## Key risk and guardrail
