## Recommended qualifying sequence
1. **Engineering hardening** — authentication via signed OIDC, real data contracts, secrets, private egress, SIEM, SLOs and cloud-deployment pipeline with threat testing.
2. **Permissioned first deployment** — an independently approved enterprise pilot; get sponsor, privacy review, legitimate systems, agreed control boundaries and costed statement of work.
3. **Measure** — validated acceptance scenarios, user-rated quality, downstream exception outcomes, production p50/p95/p99, failure rate, time saved and human review burden.
4. **Operational maturity** — failover, replay, rollback, alerts, bias testing, versioned releases, support and incident register.
5. **Complete agent application** — actual recorded video, production certificates/links, deployment reference consent, agent and developer CV, signed evaluation evidence.

**Do not create fake employer/client references, staged screenshots labelled production, fabricated outcome data, or claim that executing code is equivalent to a production agent.**
