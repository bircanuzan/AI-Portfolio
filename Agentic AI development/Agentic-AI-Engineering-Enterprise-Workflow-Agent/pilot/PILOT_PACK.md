# HumanEvoX paid pilot offer — template, no client contract yet

**Offer:** 2–4-week controlled workflow-automation pilot for one low-risk service queue. A client provides only approved synthetic or de-identified documents and a read-only sandbox API. External writes are excluded from initial scope.

## Discovery and safeguards
- Written client authorization, named sponsor, scope and procurement approval.
- Confirm data residency, privacy notice/consent/legal basis, retention, DPA, subprocessor/model access, enterprise IT policies.
- Baseline current hours/tickets, time-to-answer, escalation rate and human processing cost.
- Determine workflow boundaries, document owner, API access with least privilege, and non-goals.
- Agree testing dataset, thresholds, termination/rollback, incident contact, ownership of deliverables.

## Contracted milestones
| Phase | Deliverable | Acceptance |
|---|---|---|
| Week 1 | Process & risk assessment; baseline and scope | Signed plan and permitted data matrix |
| Week 2 | Read-only agent prototype and approval path | Source-linked demo and role/access review |
| Week 3 | Adversarial and user acceptance testing | Signed exception and test log |
| Week 4 | Measured results, handover & go/no-go | Sponsor acceptance; rollback documented |

## Commercial scope
Fee: **one-time fixed pilot fee to be agreed in writing**; no invented amount, client or signed contract. Pilot explicitly excludes HR decisions, production HRIS writes, biometric/psychometric inference and high-risk employment decision automation.

## Value proof
Report observed reduction in manual handling, answer accuracy, escalation, correction time, p95 latency, cost per completed request and exception safety. Include denominators, dates, baseline source and failed cases. Do not present targets as achieved results.

## Evidence for genuine client work
Save signed permission (private), dated SOW, issue tracker, delivery receipts, acceptance, de-identified metrics and reference contact with consent. Public GitHub may link to a redacted anonymized case only after explicit client approval.
