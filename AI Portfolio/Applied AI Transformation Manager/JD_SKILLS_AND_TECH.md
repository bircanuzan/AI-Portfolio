## Applied technical and AI stack

**Actually utilized in this repository:** Python 3 (csv/json/pathlib/unittest), typed numerical logic, synthetic CSV, GitHub version control and GitHub Actions automation.

**Architecture options for an authorized customer engagement, not used/integrated here:** Cognition Devin engineering agent; Devin-approved APIs/SDK; GitHub/GitLab repositories, pull-request and code-review APIs; Jira/Azure DevOps; Microsoft Entra ID/SSO; Azure AI Foundry for independent governance/evaluation work where appropriate; SQL data warehouse, Power BI/Power Query; OpenTelemetry/application tracing; security scanners and secrets vault.

**Operating controls:** authenticated least privilege; data access and residence review; tool allowlists; human approval before merge/deploy; versioned tests; adverse outcome and prompt-injection evaluations; agent run/consumption tracking; team skills training, champions and rollback.

## Mandatory qualification caveat

Cognition asks for a Computer Science/Electrical Engineering degree, professional SWE internship/employment and 3–5 years in Big Three strategy consulting, plus strong account growth. The user's known professional evidence does not establish these. No project or list of tools should be used to invent those qualifications.
