# 03 — Cross-Functional Rollout and Value Assurance

**Business challenge:** AI pilots can show high usage yet fail to reduce customer delays or improve service quality. Transformation must be measured against a business-owned baseline.

## Deliverables
- [90-day cross-functional rollout and governance](rollout_playbook.md)
- [Workshop and requirements pack](stakeholder_workshop.md)
- [KPI dictionary and release gates](value_scorecard.csv)

## Discipline
Business strategy → work design → platform/permission validation → process redesign → supervised pilot → human training → UAT and independent quality check → finance-reviewed value → go/no-go/rollback.

## Team / accountabilities
CEO/business sponsor: value and scope; Business Advisory: operating model; Talent Management: role/skill impacts; AI/IT: technical configuration; Security/Data Owner: access and retention; HR/Legal: people/data policy; process managers: review effort and outcomes; Finance: costs, benefits and no double counting; employees: feedback.

**Tools and technical options:** SQL/Power Query/Power BI for aggregated baselines; Copilot Studio/Power Automate or approved SaaS native connectors for workflow execution; Teams/SharePoint or Google Workspace for training/knowledge; Python regression tests and JSONL event/quality telemetry. These are proposed implementation options, **not** all tools actually operated.

**Evidence:** illustrative rollout and KPI design only. Numeric thresholds must be agreed with actual users, business owners and risk teams; no synthetic sample claimed as verified enterprise performance.
