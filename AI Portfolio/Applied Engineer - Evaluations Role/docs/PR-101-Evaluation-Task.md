## AI agent task prompt

> You are modifying an invoice calculation module. Add an optional decimal discount rate (between 0 and 1), apply it to the subtotal before calculating tax, reject invalid inputs, and return stable two-decimal string amounts. Use decimal arithmetic and half-up rounding; do not regress no-discount behavior. Explain changed functions and run the automated tests before submitting your patch.

## Acceptance and executable checks

1. Correct subtotal for multiple line items.
2. Discount applied **before** tax; catch incorrect gross-tax order.
3. Correct half-cent rounding, e.g., 0.30 × 0.05 → 0.02.
4. Reject empty lists, negative prices, invalid quantities and discount rates.
5. Preserve no-discount, zero-tax behavior.
6. Identify environment failures separately from code failures.
7. Return machine-readable case IDs, expected vs. observed, classification and weighted score.
