## Source integrity

- Existing project code, tests, original names and historical URLs remain in place. These new capability directories are **navigation and new-demo layers**, not a destructive migration of the existing 36 AI project collections.
- The original project README controls the evidence level; no client deployment, certifications, savings or model quality results are implied by folder titles.
- The two new runnable projects use entirely fictional data and local standard-library Python.
