# AI Project & Program Management

HumanEvoX | A separate top-level portfolio for practical project coordination, delivery, programme management and enterprise AI portfolio governance.

## Four original project folders

1. **[Project 27 — AI Project Documentation & Implementation Support](27_AI_Project_Documentation_and_Implementation_Support/)** — scope definition, requirements documentation, user guidance and feedback logging in an independent fictional demonstration.
2. **[Project 38 — AI Portfolio & Governance PMO (ServiceNow, SPM)](38_AI%20Portfolio%20%26%20Governance%20PMO%20(ServiceNow%2C%20SPM)/)** — simulated AI demand/portfolio lifecycle with approvals, funding, RAID, UAT and benefit controls; Python data-quality dashboard and tests.
3. **[Project 40 — Technical Program Management](40_Technical_Program_Management/)** — fictional fintech integration case with roadmap, API/webhook handoffs, risks and milestones, cross-project capacity and Python health reporting.
4. **[AI Project Portfolio Management](AI-Project-Portfolio-Management/)** — simulated regulated-payments enterprise AI portfolio intake, prioritisation, stage gates, BRD, governance, delivery readiness, executive status and benefits tracking.

**Evidence and qualifications:** These are original instructional work samples and fictional/synthetic project cases. They do **not** establish employment at the named organisations, live ServiceNow/SPM configuration, project deployments, realised benefits, or professional certifications. Each folder keeps its original project documents and limitations.

## Try the local demonstrators

From the repository root, with Python installed:

```bash
python "AI Project & Program Management/38_AI Portfolio & Governance PMO (ServiceNow, SPM)/src/portfolio_quality.py"
python -m unittest discover -s "AI Project & Program Management/38_AI Portfolio & Governance PMO (ServiceNow, SPM)/tests" -v
python "AI Project & Program Management/40_Technical_Program_Management/src/project_health.py" --as-of 2026-10-29
python -m unittest discover -s "AI Project & Program Management/40_Technical_Program_Management/tests" -v
```

No external service, credential or client environment is needed for these synthetic offline examples. See each project README for other usage details.
