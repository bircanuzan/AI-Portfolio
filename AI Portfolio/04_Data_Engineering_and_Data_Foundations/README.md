Data quality, ingestion, schema contracts, traceable transformations, metadata and data governance.

**Portfolio navigation:** open each project subfolder below. The source for established projects is kept at its original path to preserve existing GitHub links, test workflows and historical provenance; the new subfolders provide capability-first entry points, not copied production deployments.

## Projects

- **[Enterprise Data Architecture](Enterprise_Data_Architecture/)** — Enterprise data architecture and quality gates; distinguish local implementation from cloud designs.

## How to assess maturity

- Source code and local tests show what was actually implemented.
- Architecture and operating-model documents describe proposed implementation, not completed production deployment.
- Synthetic datasets and hypothetical costs are not actual client figures or achieved returns.
