# Data Analytics & Machine Learning

Exploratory analysis, ML baselines, data and model evaluation, experiment tracking and decision-quality evidence.

**Portfolio navigation:** open each project subfolder below. The source for established projects is kept at its original path to preserve existing GitHub links, test workflows and historical provenance; the new subfolders provide capability-first entry points, not copied production deployments.

## Projects

- **[AI Model Evaluation](AI_Model_Evaluation/)** — Synthetic model evaluation, classifier and forecasting demonstration projects.
- **[Machine Learning Projects](Machine_Learning_Projects/)** — ML portfolio source collection with reproducibility and evidence limitations.
- **[Experiment Tracking](Experiment_Tracking/)** — MLflow/W&B-style example experiment records and quality thresholds.
- **[Workforce Data Analytics](Workforce_Data_Analytics/)** — Applied people analytics and workforce information projects.

## How to assess maturity

- Source code and local tests show what was actually implemented.
- Architecture and operating-model documents describe proposed implementation, not completed production deployment.
- Synthetic datasets and hypothetical costs are not actual client figures or achieved returns.
