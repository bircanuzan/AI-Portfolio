# Talent Development — Executive Global Capability Portfolio

**60 distinctive subsection projects across 12 strategic capability sections.** Built as a **Head of Talent Development interview-aligned design portfolio** for a fictional international clean-energy organization, rather than proof of an employer implementation.

**Every subsection** contains a standalone project README, a worked decision/control artifact and an evidence capture CSV. The cases are synthetic; real system use, vendor deployments, assessment licensing, employer approvals and ROI are **not claimed**.

## How to present in an interview
1. Open one decision project relevant to the question.
2. Explain its **problem, data inputs, root cause, intervention options, governance, decision and measurable outcomes**.
3. Demonstrate the artifact while explicitly distinguishing illustrative assumptions from real delivery evidence.
4. For reporting questions, link to the pre-existing Oracle-style demo instead of claiming production Oracle or Masdar PMR access.
