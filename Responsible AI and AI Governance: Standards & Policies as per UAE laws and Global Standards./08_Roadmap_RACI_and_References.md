# 08 — Roadmap, RACI and Primary References

## Proposed 30 / 60 / 90-day implementation

| Phase | Main work | Deliverables / exit gate |
|---|---|---|
| Days 1–30 | Inventory AI use cases, distinguish UAE law from guidance, identify affected people and systems | Approved inventory; initial legal applicability notes; impact-assessment plan |
| Days 31–60 | Define policy and controls, map ISO/NIST methods, assign RACI, select safe prototype tests | Draft policy; control crosswalk; test protocols; documented residual risks |
| Days 61–90 | Execute authorized evaluations, resolve findings, train reviewers, decide go/hold and monitoring | Real evidence pack (if executed); decision log; incident playbook; review cadence |

## RACI (illustrative)

| Activity | Exec sponsor | AI governance | Legal/privacy | Security | HR/business | Evaluator |
|---|---|---|---|---|---|---|
| Approve policy | A | R | C | C | C | I |
| Determine legal applicability | I | C | A/R | C | C | I |
| Approve purpose and human workflow | I | C | C | C | A/R | C |
| Technical threat and vendor risk | I | C | C | A/R | C | R |
| Conduct AI evaluation | I | A | C | C | C | R |
| Authorize production | A | R | C | C | R | C |
| Monitor and respond | I | A | C | R | R | C |

R = responsible, A = accountable, C = consulted, I = informed.
