# AI Transformation | HumanEvoX portfolio

**Purpose:** Turn scattered AI subscriptions, uneven workflows and unclear ownership into a coherent, measurable and governed enterprise transformation plan. Designed around the **AI Transformation Consultant** problem described on Click Start's public careers page.

**Evidence:** Independent fictional case for "Atlas UAE Shared Services" with synthetic company inventory, invented process examples, executable **local deterministic Python** decision logic and tests. No Click Start affiliation, live client system, tenant, API connection, external LLM execution or actual savings are claimed.

## Integrated project sequence

1. [01 — Enterprise AI Discovery and Subscription Rationalisation](01_Enterprise_AI_Discovery_and_Subscription_Rationalisation/README.md): strategy workshops, current-state app inventory, spend/adoption analysis, duplication, data classification and transformation roadmap.
2. [02 — Controlled Human–AI Workflow Pilot](02_Controlled_Human_AI_Workflow_Pilot/README.md): source permission checks, review/approval routing, exception handling, audit trail and reproducible offline Python implementation.
3. [03 — Cross-Functional Rollout and Value Assurance](03_Cross_Functional_Rollout_and_Value_Assurance/README.md): sponsor decisions, cross-functional RACI, 30/60/90 rollout, UAT, training and real-value measurement design.

## Technology architecture — choices vs actual use
- **Executed demonstration:** Python 3 standard library; synthetic CSV/JSON; local test fixtures; rule-based permission workflow.
- **Evaluated for a real client, not connected/tested here:** Microsoft 365 Copilot / Copilot Studio / SharePoint / Power Automate; Azure OpenAI/OpenAI API; Microsoft Entra RBAC; Google Workspace/Gemini; Zapier/Make; Power BI; Salesforce/HubSpot and approved connectors.
- **Selection guardrails:** identity and least privilege; source permissions and consent; data residency; DLP; model evaluation; human approval; observability; cost per verified outcome; records retention; incident ownership; versioned change control. Use IT, security, HR, legal and business-owner approvals.
- **Important distinction:** No live LLM or external API is called. A configurable, production-eligible design is not itself production evidence.
