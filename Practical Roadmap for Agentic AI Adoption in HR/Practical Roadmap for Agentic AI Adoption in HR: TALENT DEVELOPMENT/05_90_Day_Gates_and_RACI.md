# Step 5: SCALE — Gated 30/60/90-day adoption and organizational accountability

## Sequencing and dependencies (planning illustration)

| Period | Activities | Required exit evidence |
|---|---|---|
| Days 1–15 | Baseline process, stakeholder interviews, compare agent with simpler automation, choose use case | **G0** business demand and accountable sponsor |
| Days 16–30 | Readiness scoring, legal/data/instrument rights, human workflow and threat model | **G1** readiness evaluation; mandatory blockers cleared |
| Days 31–45 | Build secure restricted demo and versioned authorized sources; identity, data and action controls | **G2** inspected system boundaries, no forbidden capabilities |
| Days 46–60 | Execute negative/synthetic tests and supervised shadow evaluation; correct defects | **G3** all critical tests passed, real denial traces, approved incident fallback |
| Days 61–75 | Run a limited authorized user pilot against manual workflow | **G4** measured value, accuracy, fairness, privacy and reviewer outcomes |
| Days 76–90 | Re-test after changes, second stable cohort where appropriate, assess costs and readiness to expand | **G5** independently signed scale / extend / hold decision |

Governance must precede user exposure; the planning windows may extend if there is insufficient data or unresolved harm.

## Mandatory release-to-scale conditions

1. **Value proven:** manager and employee time per mutually accepted skill-linked development plan improves against a suitable manual/simpler comparator; full run cost and human rework included.
2. **Reliability proven:** independent human adjudication shows KPI targets and stable test outcomes across at least two review windows; difficult and ambiguous cases included.
3. **Risk boundaries proven:** actual authorized adversarial tests confirm tool-level denial, sensitive data protection, source versioning, human decision ownership, auditable activity and emergency disable.
4. **Organization ready:** workforce communication, reviewers, service/incident staffing, leadership responsibility and re-training/change impacts confirmed.
5. **Signed authority:** Talent Development Lead, security, privacy/legal and AI governance review residual risk and explicitly authorize the next limited cohort.

**Expansion sequencing:** New roles after employee trust, equitable opportunities, verified learning paths and ongoing human choice.

Never add new autonomy, production data, HRIS write access, wider user groups or new jurisdictions silently. Each material increase requires re-assessment and another gate decision.

## RACI (proposed)

| Item | Talent Development Lead | IT/Security | Legal/Privacy | Human SME/Reviewer | AI Governance |
|---|---|---|---|---|---|
| Value and use-case authorization | A/R | C | C | C | C |
| Policy / content and task review | A | I | C | R | C |
| Identity, integrations, tool deny | C | A/R | C | I | C |
| Data and jurisdiction review | C | C | A/R | C | C |
| Testing, acceptance and risk gates | A | R | C | R | R |
| Incident containment | I | A/R | C | C | R |
| Scale / hold decision | A | C | C | R | R |

A = Accountable, R = Responsible, C = Consulted, I = Informed. Named humans must be assigned during real planning.

## Go/no-go template

Decision: **UNASSESSED** (GO / CONDITIONAL EXTEND / REWORK / HOLD / REJECT). Reference baseline, approved impact/legal review, completed test logs and failures, KPI evidence, reviewer feedback, signed residual risk, human incident owner and next reassessment date. The absence of evidence is not a GO.
