# AI Governance, Risk & Responsible AI Portfolio

HumanEvoX | Four original project collections consolidated without dropping source files, code, tests, CSV registers, governance templates or synthetic evidence.

**Evidence integrity:** These projects are educational designs, reproducible local demonstrations, and fictional UAE-oriented scenarios. No enterprise deployment, live regulatory integration, real client audit, ISO certification or production agent performance is claimed.

## Four project collections

1. **[Project 37 — AI Risk Management and TEVV](37_AI_Risk_Management_and_Testing_Evaluation_Verification_and_Validation/)** — NIST AI RMF-aligned risk intake, policy freshness, independent testing and evaluation, evidence dashboard, incident/exception logs and supplier assurance.
2. **[Project 44 — AI Ethics, Responsible AI and Governance](44_AI_Ethics_Responsible_AI_and_AI_Governance/)** — AI governance operating model, risk/impact assessment, privacy, control library, fairness tests, vendor review and executive assurance pack.
3. **[Managing Risk, Security, and Ethical Considerations for Agentic AI](Managing%20Risk%2C%20Security%2C%20and%20Ethical%20Considerations%20for%20Agentic%20AI./)** — delegated authority, least privilege, prompt/tool security, privacy, human oversight, incident response and practical HR agent threat scenarios.
4. **[Responsible AI Standards and Policies — UAE and Global](Responsible%20AI%20and%20AI%20Governance%3A%20Standards%20%26%20Policies%20as%20per%20UAE%20laws%20and%20Global%20Standards./)** — Dubai/UAE frameworks, relevant legislation, global ISO/NIST/OECD/UNESCO references, policies, impact assessments, risk-control mapping and testing approach.

## How to navigate and run demonstrations

Each project retains its original folder name, file hierarchy and project-specific README. Links between folders within this consolidated portfolio stay at the same relative depth.

From the **repository root**, run the Project 37 example with:

```bash
python "AI Governance, Risk & Responsible AI Portfolio/37_AI_Risk_Management_and_Testing_Evaluation_Verification_and_Validation/src/assurance_dashboard.py"
python -m unittest discover -s "AI Governance, Risk & Responsible AI Portfolio/37_AI_Risk_Management_and_Testing_Evaluation_Verification_and_Validation/tests" -v
```

For Project 44, see its [run and test guide](44_AI_Ethics_Responsible_AI_and_AI_Governance/RUN_AND_TEST_GUIDE.md). Local Python tests use synthetic sample data only.
