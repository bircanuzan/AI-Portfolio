# AI Product Evaluator | Agent Instruction & Response Quality Bench

**Status:** Self-directed synthetic portfolio evaluation; not externally commissioned or claims of paid model-evaluator work.

## Objective
Assess sample model/agent outputs for instruction fidelity, completeness, correct escalation and reproducible written reporting under detailed protocols.

**Artifacts:** evaluation.py implements deterministic checklist scoring; tasks.json supplies fictional test cases; TASK_AND_ACCEPTANCE.md establishes human review and QA controls.

**Run:** `python evaluation.py`; results print as JSON. This checks structured task conformity, not nuanced semantic truth or real model quality.

**Skills mapped:** AI model evaluation, agent QA, high-volume review protocols, anomaly documentation, instruction following, quality calibration and evidence recording.
