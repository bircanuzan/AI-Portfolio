# HR Shared Services | UAE Employee Operations, Recruitment & PRO Governance

**Project type:** Independent portfolio / illustrative operating model (2026)  
**Context:** UAE multi-account employer / contact-centre-style workforce  
**Status:** Proposed design and sample controls; **not** a production implementation at sector_organization.  
**Prepared by:** Bircan Uzan | HumanEvoX

## Objective
Build a repeatable and auditable HR Shared Services framework linking recruitment, onboarding, employee records, PRO/immigration coordination, payroll handoffs, transfers, exits, escalation management, and frontline service delivery.

## Operating workstreams
1. **PRO / immigration coordination:** expiry watchlists, sponsorship-transfer planning, third-party service providers, case status, approval evidence, legal/HR escalation.
2. **Employee administration:** joining packs, work-authorisation checkpoints, contract and Emirates ID document controls, record retention, lifecycle changes, exit checklists.
3. **Recruitment:** approved requisitions, source-to-offer pipeline, offer acceptance, pre-joining checks, recruitment turnaround and onboarding readiness.
4. **Governance:** accountable process owner, SLA and exceptions dashboard, compliance review, daily operational huddles and monthly leadership reporting.

Never store live identity documents in a public GitHub repository.
