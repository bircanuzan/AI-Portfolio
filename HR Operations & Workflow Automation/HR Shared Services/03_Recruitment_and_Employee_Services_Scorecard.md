# 03 | Recruitment & Employee Services Scorecard

**Status:** Proposed KPI definitions and reporting examples.

| KPI | Calculation / definition | Typical frequency | Data source |
|---|---|---|---|
| Requisition fulfilment | Hires started / approved positions due to start | Weekly | ATS + headcount approval |
| Time to shortlist | Days from approved requisition to agreed shortlist | Weekly | ATS |
| Offer acceptance | Accepted offers / offers issued | Weekly | ATS |
| On-time joiners | Joiners satisfying all required gates by planned start / total planned joins | Daily / weekly | HCM + case queue |
| HR case SLA attainment | Cases closed within target / eligible closed cases | Daily / monthly | Case system |
| Aged open cases | Active cases exceeding threshold by category and owner | Daily | HR Ops tracker |
| PRO service timeliness | Completed PRO cases within approved target / eligible cases | Weekly | Restricted PRO tracker |
| Document control completeness | Records passing required-field control / records checked | Weekly | HCM sample review |
| Workforce readiness | Joiners cleared for start / planned upcoming joiners | Daily | HR / Ops reconciliation |
| Supplier rework | Returned cases requiring re-submission / submitted cases | Monthly | PRO provider / case system |

## Data and governance requirements
- Capture numerator, denominator, owner, period and case exclusions to prevent misleading scores.
- Separate employer and supplier delays to support root-cause analysis.
- Report ageing bands, critical exceptions and forecast next-week volume alongside percentage metrics.
- Show trend by entity/account only where permitted under access and data-protection rules.
- Every exception has a named owner, due date and closure evidence.

## Suggested supervisor review
**Morning:** joiner-readiness forecast, urgent expiries, aged critical issues.  
**Weekly:** recruitment funnel, suppliers, SLA misses and action log.  
**Monthly:** service scorecard, workforce plan variance, compliance exceptions, system improvements and lessons learned.

## Example reporting narrative
'Week 1 showed a hypothetical joining-readiness shortfall concentrated in two accounts. Proposed response: confirm document dependency owners, bring forward pre-boarding checks, and assign a daily cross-functional exception review. Escalate any work-authorisation uncertainty to qualified specialists.'

All values and workflow narratives are **illustrative**, not sector_organization operational results.
