# Evidence Classification and Claims Boundary

**Demonstrated here:** independently authored scenario prompts, evaluation method, rubric, deterministic evaluation script, formula-based case engine, unit-test harness, generated sample document/spreadsheet/deck templates and fictional consulting outputs.

**Not demonstrated:** paid AI-labeling engagements, human-reviewed empirical model performance, real external foundation-model inference, fine-tuning, blind multi-rater calibration, deployment to a client, production Excel audit, actual investment returns or operational improvements.

**Testing boundary:** `tests/` validates this repository's small deterministic utilities. It cannot prove that a generated executive narrative is accurate, attractive, accessible or decision-ready. Human expert review is required.

**Responsible usage:** Never upload actual client records without authorization. When comparing model-generated outputs, retain prompt versions, source snapshots, annotation criteria, reviewer rationale and privacy controls. Any benchmarks constructed from confidential or copyrighted materials must follow rights and access rules.

**Future enhancements (proposed only):** multi-rater adjudication, blinded A/B comparisons, data-leakage checks, slide and DOCX rendering tests, Excel cached-value reconciliation, and model-provider telemetry.
