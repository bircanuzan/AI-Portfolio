## How to assess this work

1. Open an individual project. Read its README, execution instructions and evidence limits.
2. Distinguish actual local code execution from unexecuted cloud/API design and business hypotheses.
3. All newly developed cross-category demos use invented input data. External ROI claims, AI vendor price quotations and real-world cost savings are **not** asserted.
