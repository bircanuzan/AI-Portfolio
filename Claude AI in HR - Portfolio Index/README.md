# Claude AI in HR — 50 Original Project Folders

**Repository:** [AI-in-HR-Portfolio](https://github.com/bircanuzan/AI-in-HR-Portfolio)

## Scope and evidence integrity
This is an **independently created portfolio** of **50 original HR agents/workflows and 50 corresponding Claude-compatible skills**, distributed across **10 HR functions**. These are **not** the seller's proprietary 50 agents or private 50 skills. The [referenced Gumroad product](https://kumail.gumroad.com/l/HR) publicly advertises 50 agents, 50 skills, and 10 HR functions; its detailed proprietary inventory and content were not available for inspection. The topics below are our own interpretation of those publicly described functional areas, not a representation of the exact purchased package.

Every project includes a tailored README, a portable `SKILL.md`, a fictional JSON case and a five-case acceptance protocol. **All 50 are designed but not yet tested in Claude**. No real client delivery, agent execution, candidate assessment or validated metric is claimed.

**Created:** 2026-11-02. **Portfolio owner:** Bircan Uzan / HumanEvoX. **Primary uses:** HR transformation, HR agent governance, Claude skill design, responsible workflow implementation and evidence-led demos.

## Reproducible next steps
1. Pick one folder; review its workflow and guardrails.
2. Load `SKILL.md` into an authorized Claude environment, run only synthetic inputs, and capture the verbatim responses.
3. Run all five acceptance cases and record actual results — including failures, model version, source versions, reviewer, and timestamps.
4. Publish redacted evidence only after verification; update status from **NOT RUN** rather than fabricating performance results.

## Governance
No live employee/candidate PII, no autonomous hiring or pay decisions, no unverified labor/immigration advice, and no external messages without human confirmation. Organizational HR, security, legal and policy owners remain accountable.
